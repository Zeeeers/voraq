# Voraq Desktop

Descargas de Voraq Desktop para Linux x64 y Windows x64. Este repositorio sólo aloja las versiones publicadas: el código fuente no está aquí.

- **Linux:** descarga `Voraq-<versión>-x86_64.AppImage`, dale permiso de ejecución y ábrela.
- **Windows:** descarga y ejecuta `Voraq-Setup-<versión>.exe`. Se instala para tu usuario, sin permisos de administrador. La primera vez que abras Voraq, Windows pedirá permiso de administrador una sola vez para preparar el aislamiento en el que corren los comandos de los agentes.

Voraq se actualiza solo: descarga cada versión nueva en segundo plano y la instala al reiniciar. Sólo acepta actualizaciones firmadas por Zeeers.
